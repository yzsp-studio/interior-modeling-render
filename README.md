## 🇬🇧 English

Starting from a floor plan, site photos, a written brief or reference material, it produces an editable interior scheme and, once confirmed, delivers a Blender model plus a photoreal one-take walkthrough video. The pipeline first identifies which kind of spatial input it received, then builds or rebuilds a coloured 2D floor plan, generates a refined axonometric view, calls Blender to model and returns a model package, and finally records the interior with a main camera in a single continuous shot. A canvas minimum-delivery rule is enforced across every stage, so there is always a visual artefact to review instead of prose alone. It does not provide construction-safety advice.

### ✨ What it does

- Floor plan, site photo, written brief or reference in → editable interior scheme out
- Identifies the spatial input type, then builds or rebuilds a coloured 2D floor plan
- Generates a refined axonometric view, calls Blender to model and returns a model package
- Records a photoreal one-take interior walkthrough with a main camera
- Canvas minimum-delivery rule across the whole pipeline keeps every step reviewable
- Modeling and recording start only after the scheme is confirmed; no construction-safety advice
